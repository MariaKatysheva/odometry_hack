# Резервная одометрия трамвая — автономный запуск

Выбранная модель: **фильтр Калмана с IMM (норма / передняя / задняя / обе тележки) + признак 2**
(ускорение колёс против модели привода — для проскальзывания обеих тележек).
Вход — только колёса и ручка контроллера; GNSS — только стартовая точка.

## Какие файлы нужны

```
solution/
├── run_offline.py              запуск на записанном рейсе (потоково, без будущего)
├── tram_odometry/
│   ├── estimator.py            оценщик: скорость, путь, режимы проскальзывания
│   ├── bag.py                  чтение rosbag2 (.db3) без ROS
│   ├── start.py                начальная выставка по GNSS (окно 20 с, медиана, выбор направления)
│   └── track.py                карта пути: s → x, y, z (Pathgraph), уклон; поиск старта по lat/lon
└── data/
    ├── route_map.csv           линии рельсов обоих направлений с шагом 1 м (s, x, y, lat, lon, alt, grade, …)
    ├── pathgraph_AB.json       Pathgraph «Таллинская → Щукинская» (высота рельса)
    ├── pathgraph_BA.json       Pathgraph «Щукинская → Таллинская»
    ├── drive_gp_table.csv      модель привода: ускорение и его разброс по (ступень, скорость) — физика + GP
    ├── slip_calib.json         калибровка признака 2 по чистой езде (порог 99,9 %, шум ускорения колёс)
    └── terminal_BA.json        пути конечной «Таллинская» (OpenStreetMap) и частоты веток — build_terminal.py
```

Больше ничего не нужно: остальные скрипты проекта — анализ, обучение и сравнение вариантов.

**Зависимости:** Python 3, `numpy`, `pandas`. (Без `scipy`, `pyproj`, `torch`.)

## Запуск

```bash
python3 solution/run_offline.py data/30618_0e41eac3              # прямо из rosbag2 (.db3), результат: estimate_30618_0e41eac3.csv
python3 solution/run_offline.py data/30618_0e41eac3 out.csv      # или в указанный файл
python3 solution/run_offline.py export/30618_0e41eac3            # то же из выгрузки CSV (export_all.py)
```

Папка рейса — либо исходный rosbag2 из `data/` (читается напрямую, без ROS: `tram_odometry/bag.py`),
либо выгрузка `export_all.py` (`wheels.csv`, `cmd.csv`, `gnss_fix.csv`). GNSS — только для стартовой точки.

**Выход** (`estimate_<рейс>.csv`), одна строка на **каждое** входное сообщение — колёс (≈10 Гц) и контроллера (≈20 Гц),
итого ≈ 27–30 Гц на всех 122 рейсах (требование ≥ 10 Гц). На сообщении контроллера выдаётся прогноз по модели
привода (`Estimator.peek`), состояние фильтра не меняется — точность та же, что при выдаче только по колёсам.

| столбец | смысл |
|---|---|
| `stamp` | время входного сообщения (как `header.stamp`) |
| `v` | продольная скорость, м/с → `/result/velocity` |
| `x, y, z` | положение base_link в системе Pathgraph (UTM 37N − (300 000, 6 100 000)), м → `/result/position` |
| `s` | путь вдоль рельсов своего направления, м |
| `direction` | `AB` (Таллинская → Щукинская) или `BA` |
| `sigma_v` | неуверенность скорости, 1σ, м/с |
| `sigma_s` | неуверенность положения вдоль пути, 1σ, м (растёт с пройденным путём — износ колёс) |
| `slip_both`, `stopped` | флаги: проскальзывание обеих тележек, стоянка |

## Как вызывать оценщик в своём коде (например, в ROS 2-ноде)

```python
import json, pandas as pd
from tram_odometry.estimator import Estimator, Params
from tram_odometry.track import Track, DATA

params = Params(anchors=False, gate_v=1e9, gp_sigma='const', imm=True,
                drive_table=pd.read_csv(DATA / 'drive_gp_table.csv'),
                slip_calib=json.load(open(DATA / 'slip_calib.json')))
track = Track('AB')                       # направление — по стартовой точке (Track.locate)
est = Estimator(track, params)
est.init(t0, s0)                          # s0 — путь base_link на старте, м

# на каждом сообщении:
est.on_cmd(t, position)                   # /vehicle/driver_position_cmd, position ∈ −15…15
est.on_wheels(t, front_kmh, rear_kmh)     # /vehicle/*_bogie_velocity (одна из них может быть NaN — пропуск)
v, (x, y, z) = est.output()               # публиковать с header.stamp = t
sigma_v, sigma_s = est.sigma()            # 1σ: скорость, м/с; положение вдоль пути, м → covariance

# на сообщении контроллера (чтобы частота выдачи была ≥ 10 Гц даже при пропусках колёс):
est.on_cmd(t, position)
v, (x, y, z) = est.peek(t)                # прогноз на момент t, фильтр не меняется
```

Колёса подаются **в км/ч, как в данных** (в модели делятся на 3,6). Если пришла только одна тележка —
вторую передавать как `NaN`.

## Стартовая точка

- Есть GNSS в первые секунды — RTK-точки первых 20 с проецируются на обе линии; направление — линия, к которой
  ближе все точки окна, при условии, что трамвай не стоит в самом конце линии и путь по ней не убывает
  (на конечной «Щукинская» конец AB и начало BA проходят в метрах друг от друга — по одной точке путается).
  Путь — с поправкой на вынос антенны по tf (master −9,873 м, rover +2,563 м).
- GNSS есть, но дальше 30 м от обеих линий (депо, другой путь) — как без GNSS.
- GNSS нет — публикуется **относительная одометрия** от старта: `x` = пройденный путь, `y = z = 0`
  (разрешено заданием).
